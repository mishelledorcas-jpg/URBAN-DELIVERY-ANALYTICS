# Urban Delivery Performance Analytics

## Project Overview
Analyze logistics performance datasets, track fulfillment metrics, and isolate operational inefficiencies across regional delivery channels. Build interactive, automated dashboards to help business leads monitor transit operations, identify bottleneck patterns, and reduce customer turnaround times.

## Core Technical Stack
* **Analytics Engine:** Power BI Desktop / Power BI Service Cloud
* **Data Modeling:** Relational Schema Mapping & DAX (Data Analysis Expressions)
* **Underlying Logic:** Structured data logs, fulfillment timestamps, and delivery tracking matrices

## Project Execution & Workflow Steps
* **Ingest and Validate Logistics Data:** Parsed raw transit records and delivery performance tables to ensure data consistency before modeling.
* **Map Operational Schemas:** Structured relational data models linking geographic regions, fulfillment channels, and order timeline logs.
* **Construct Telemetry Dashboards:** Built multi-view interactive reporting tabs inside the "URBAN COMPANY DELIVERY REPORT" to highlight processing delays and track active regional targets.
* **Optimize Visual Interfaces:** Refined canvas elements and filtering systems based on workflow requirements to maximize business scannability.

## Key Insights Delivered
* Isolated exact fulfillment bottlenecks contributing to regional transit lags during high-volume operational cycles.
* Mapped delivery duration trends to establish clearer, data-backed timeline expectations for end-to-end customer logistics pipelines.
